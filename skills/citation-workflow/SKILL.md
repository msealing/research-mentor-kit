# 论文引用工作流 (Citation Workflow)

让论文的"正文引用标注 + 文末参考文献列表"形成闭环：正文每句话有出处，文末列表真实可查。

## 铁律（最重要）

1. **禁止编造引用**：所有引用必须来自真实文献——Obsidian 文献库、检索结果、用户提供的文献。编造文献 = 学术不端。
2. **每条引用可追溯**：引用必须有 DOI 或完整出处（作者/年份/期刊/卷期页码）。
3. **正文和列表一一对应**：正文标注的每条引用，文末列表必须有；列表里的每条，正文必须标过。

## 引用来源（按优先级）

1. **Obsidian 文献库**（`{{OBSIDIAN_LIBRARY_DIR}}`，默认 `{{OBSIDIAN_VAULT}}/科研/文献库/`，见 README「环境变量」）：已入库文献优先使用（元数据真实）
2. **文献检索**：文献库没有时，用 `nature-academic-search` 检索真实文献，检索到后先入库（`paper-to-obsidian`）再引用
3. **用户提供**：用户给的文献（PDF、DOI、题录）

## 正文标注方法

### LaTeX 论文（推荐）
- 正文引用位置插入 `\cite{key}`，key 用 `作者姓氏+年份`（如 `\cite{zhang2021}`）
- 文末用 `\begin{thebibliography}{99}` + `\bibitem{key}` 生成列表
- 示例：
  ```latex
  已有研究表明，导师的神经质特质与研究生压力显著正相关\cite{zhang2021}。
  ...
  \begin{thebibliography}{99}
  \bibitem{zhang2021} 张建卫，周洁，李海红。(2021). 研究生心理压力与心理健康的关系：应对方式的中介作用. \textit{研究生教育研究}, (3), 45--52.
  \end{thebibliography}
  ```

### Word 论文
- 正文引用位置加带方括号的上标数字 `[1]`、`[2]`
- 文末按出现顺序编号生成参考文献列表

## 引用格式规范

- **中文论文**：GB/T 7714 格式（作者. 题名[J]. 刊名, 年, 卷(期): 页码.）
- **英文论文**：APA 格式（Author, A. A. (Year). Title. *Journal*, Vol(Issue), pages.）
- 用户有学校模板要求时，以学校要求为准

## 工作流程

1. **确认引用需求**：写作时遇到需要引用的观点/数据/结论，先判断是否已有文献支撑
2. **找文献**：查 Obsidian 文献库 → 没有则检索（nature-academic-search）→ 入库（paper-to-obsidian）
3. **插入标注**：正文插入 `\cite{key}`（LaTeX）或 `[n]`（Word）
4. **生成列表**：文末生成参考文献列表，与正文标注一一对应
5. **核验**：用 `nature-ref-verifier` 逐条核验参考文献真实性（作者/年份/卷期/页码）

## 检查清单（论文写完必查）

- [ ] 正文每个 `\cite` 在文末列表都有对应 `\bibitem`
- [ ] 文末每条 `\bibitem` 在正文都被引用过（没有"孤儿文献"）
- [ ] 所有引用来自真实文献（有 DOI 或完整出处）
- [ ] 格式符合 GB/T 7714 或 APA（或学校模板）
- [ ] 引用位置恰当（观点归属正确，不张冠李戴）

## 常见错误提醒

- **孤儿文献**：列表里有但正文没标 → 删掉或补标注
- **悬空引用**：正文标了但列表没有 → 补列表
- **张冠李戴**：把 A 文献的观点标成 B 文献 → 引用前核对摘要
- **编造文献**：AI 生成不存在的文献 → 全部引用必须来自文献库/检索结果
