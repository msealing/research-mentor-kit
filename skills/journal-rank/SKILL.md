# 期刊分区查询 (Journal Rank)

查询期刊的学术水平等级（中科院分区、JCR 分区、影响因子），帮助用户判断目标期刊档次、辅助投稿选刊。

## 数据来源说明（重要）

- **中科院分区表**：中国科学院文献情报中心发布，2025 版为官方最后一版（2026 年起永久停更）。数据受知识产权保护，批量数据需学校图书馆购买，**个人用户可通过官方平台免费在线查询**。
- **JCR 分区**：科睿唯安发布，需订阅访问。
- **本 skill 的本地数据**：`期刊分区数据.csv` 内置少量常见期刊示例数据，仅供离线兜底和演示。**完整数据需用户自行获取后扩充**（见下方"扩充数据"）。

## 查询流程

1. **先查本地数据**：读取 `期刊分区数据.csv`，按期刊名（支持模糊匹配）或 ISSN 精确匹配。
   - 匹配成功 → 返回分区信息。
   - 匹配失败 → 告知用户本地无此期刊数据，转在线查询。

2. **在线查询指引**（本地无数据时）：
   - 中科院分区：https://www.fenqubiao.com/ （官方平台，支持刊名/ISSN 检索）
   - 或关注"期刊分区表"官方微信公众号，个人用户免费查询
   - 学校图书馆通常购买了分区表数据，可引导用户通过学校图书馆网站查询

3. **输出格式**：
   ```
   📊 期刊：<期刊名>
   - ISSN: <ISSN>
   - 中科院分区（2025版）: <大类分区> / <小类分区>
   - JCR 分区: <Q1-Q4>
   - 影响因子: <IF>
   - 学科: <学科分类>
   - 数据来源: <本地数据 / 在线查询>
   ```

## 扩充数据（让查询更全）

用户可从以下渠道获取完整分区数据，放入本 skill 目录的 `期刊分区数据.csv`（或 `{{JOURNAL_DATA_DIR}}` 下的 CSV，skill 会同时读取；该目录可通过环境变量 `JOURNAL_RANK_DATA_DIR` 覆盖）：

1. **学校图书馆**：多数高校购买了中科院分区表数据，可从图书馆网站下载（注意仅限校内使用，勿公开传播）
2. **官方平台**：fenqubiao.com 支持单刊查询，可手动记录常用期刊
3. **第三方整理**：网上有第三方整理的 CSV（注意版权与时效）

CSV 格式（UTF-8，表头固定）：
```
期刊名,ISSN,中科院大类分区,中科院小类分区,JCR分区,影响因子,学科
Nature,0028-0836,1区,1区,Q1,64.8,综合性期刊
```

## 注意事项

- 分区数据每年更新，查询时注明数据版本年份
- 中科院分区与 JCR 分区是两套体系，不要混用
- 分区只是参考，投稿选刊还要考虑期刊口碑、审稿周期、版面费
- 2025 版之后中科院不再更新，新刊可能查不到，可改用 JCR 分区或期刊官网信息
